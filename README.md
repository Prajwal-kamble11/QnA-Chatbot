# Enhanced Q&A Chatbot

This is a **Streamlit app** that allows users to ask questions and get AI-generated answers using **Groq AI** models with **LangChain**.  

## Features

- Interactive chat interface
- Selectable Groq AI models
- Adjustable response parameters (temperature, max tokens)
- Secure API key management via Streamlit secrets

## Installation

1. Clone this repository:

```bash
git clone https://github.com/Prajwal-kamble11/QnA-Chatbot.git
```

2. Navigate to the project folder:
   
```bash
cd QnA-Chatbot
```

3. Install dependencies:
   
```bash
pip install -r requirements.txt
```

4. Set your API keys using Streamlit secrets or ```.env``` for local testing.
   
5. Run the app locally
   
```bash
streamlit run app.py
```
